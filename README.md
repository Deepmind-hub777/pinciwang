# 天天拼词园 · 网页复刻版（字中找字）

> 原名「天天拼词王」，2026-11 起更名为「天天拼词园」。下文提到的《天天拼词王》指原版游戏。

纯静态网页，直接打开 `index.html` 或任意静态服务器即可运行（移动端优先）。

- `index.html / style.css / game.js`：界面与玩法
- `data/index.js` + `data/main-XX.js`：主园关卡数据，每 50 关一包、进关时懒加载。
  主园 900 关（前 632 关顺序参照《天天拼词王》公开攻略的关卡字，含多字关；其余用常用字补足）。
- `data/bushou.js`：后花园「部首与结构挑战」323 关（v6 起，替换原来的 74 关偏旁部件）。
- `fonts/brush.woff2`：马善政毛笔字体子集（SIL OFL，见 fonts/OFL-MaShanZheng.txt）
- `build/gen.py, build/levels.py`：关卡生成脚本——笔画数据来自 Make Me a Hanzi（Arphic Public License），
  对《通用规范汉字表》一级字逐个做笔画几何匹配，找出母字里能"描"出来的常用字。
  重新生成：下载 makemeahanzi 的 graphics.txt / dictionary.txt 到 build/ 后运行 `python3 levels.py`。

存档保存在浏览器 localStorage（键 `pinciwang.v1`）。

## 声音（v2）
- `audio/sfx/`：程序合成的音效（选笔、取消、按钮、答对、答错、重复、提示、金币、礼包、开局、过关）和古筝风背景音乐 `bgm.mp3`（循环），由 `build/gen_sfx.py` 生成。
- `audio/vo/`：语音（小试牛刀/渐入佳境/炉火纯青/登峰造极/无懈可击/游刃有余/略有小成/勉强过关/恭喜过关/太棒了/真厉害/好眼力/再想想/这个字已经找到过了），edge-tts `zh-CN-XiaoyiNeural`。
- `audio/zi/`：405 个答案字的读音（`<码位>_<拼音声调>.mp3`），edge-tts `zh-CN-XiaoxiaoNeural`，按关懒加载；点击已找到的字即朗读。
  多音字：用同音单音字替读（`build/tts_override.json`），并用"同音字音频几乎完全相同"做比对验证（`build/verify4.py`）。
- 首次触摸时解锁 AudioContext（iOS/Android）；文件缺失时退回浏览器 speechSynthesis。设置里可分别开关「音效与语音」「背景音乐」。

## v4（答案准确性修正，按评鉴四条）
- **按字分段判定**：多字关里每个字单独出答案，跨字的笔画永远不能拼成一个字（构建时检查 + 判题只认表内笔画组）。
- **全 IDS 后代 + 几何复核**：用 Make Me a Hanzi 的结构拆分把母字的所有部件逐层展开（`build/ids.py`），每个候选按笔形重新配对笔画（匈牙利算法）后再做仿射几何复核；另对 40 个最常用字做全笔画几何搜索。
- **笔形硬校验**（`build/stypes.py`，笔画类型来自 cnchar-order，MIT）：竖钩≠竖、横折钩≠横折、竖弯钩≠竖弯等，构建时直接拦截；再加笔画相交拓扑和轮廓接触检查（区分 土/工、人/八 等）。
- **同一组笔画只对应一个答案**：冲突时优先结构拆分给出的字，其次形状更像的；形状几乎一样时取常用字（日 > 曰）。
- 指标与复测：`build/probe.py`（丁假阳性、笔形违规、跨字组字、同集冲突、40 常用字漏收）。
- 生成：`python3 build_v4.py --fresh && python3 write_chunks.py && python3 tts_v4.py && python3 verify_v4.py`
- 存档兼容：答案表变化后，进关时自动清掉已不存在的旧记录；已通关与星级保留。
- v4.1 收紧：主园答案只认《通用规范汉字表》一级字（3500），乂/廿/弋/彡/幺/兀/亓/亍 这类部件不再算主园答案（偏旁部件在后花园）；繁体母字的笔形回退判定改为容忍弱折角（补回 簡→日、餃→交/父、騎→奇 等），繁体母字里的简体本字（贏→赢）不算。
- 复测（同一把尺子）：v3 → v4　丁笔形违规 157 → 0，同集双解 147 → 0，40 常用字漏收 1097 → 0，跨字组字 0 → 0；主园 900 关 7403 → 7766 个答案（均 8.2 → 8.6，含母字本身和 一/二/三）。

## v6（后花园改为「部首与结构挑战」）
- 玩法：每关 10 个《通用规范汉字表》一级字，楷体田字格大字。第一步选结构（独体/左右/上下/左中右/上中下/半包围/全包围/品字形），第二步四选一选部首；答错标出正确答案，答完显示部首名称、结构细类（半包围分左上/右上/左下/上三/下三/左三包围）和拼音，点大字朗读。答对 6 题过关，10 题三星、8 题二星；两步都对才算答对（+2 金币）。
- 标准：部首按 **GF 0011-2009《汉字部首表》**（201 个主部首，附形归主部首：氵→水、亻→人、扌→手、礻→示、⺈→刀……），归部按 **GF 0012-2009《GB 13000.1 字符集汉字部首归部规范》**（取左/上/外，其次右/下，多笔与少笔重合取多笔……）。界面显示常用教学形（氵、扌、亻），判题按标准主部首。
- 数据来源与交叉核对（`build/bushou/sources_3500.json` 逐字记录各来源）：
  1. 百度汉语部首（取第一个，即规范归部）：ben-hua/general_standard_chinese `gsc_pinyin.csv`（仓库 Apache-2.0，数据抓取自百度汉语）；
  2. sinobaba/hanzidict `characters.csv`（MIT）；3. mapull/chinese-dictionary `char_base.json`（MIT）部首与结构；4. pwxcoo/chinese-xinhua `word.json`（MIT）部首；
  5. Make Me a Hanzi（Arphic Public License / LGPL）IDS 拆分，用于结构复核和干扰项部件；
  6. GF 0012-2009 原文扫描件：对来源不一致的字逐页模板匹配定位，再人工逐字目视核对（`build/bushou/pages.py` 为手工转录的页→部首对照）。
- 计数：3500 字中 3067 字各来源一致，347 字来源不一致、按 GF 0012 扫描页核定（多为康熙部首与规范部首之差，如 去→土、灭→一、市→亠、对→又、有→月、果/史→丨、天/夫/末/未/才→一），5 字按 阝 左右规则核定；81 字无法确认 → 不出题。结构：mapull 与 MMAH IDS 两源对照，按约定（独体含 ⿻ 交叉结构等）归一后仍冲突的 197 字人工复核未定 → 不出题。最终题库 **3222 字**，涉及 184 个主部首、221 个显示形；结构分布：左右 1978、上下 757、半包围 279、独体 138、左中右 45、全包围 16、品字形 5、上中下 4。
- 档位：常见部首 176 关（1761 字，所属部首≥35 字，排除单笔部首与 疒）→ 少见部首 117 关（1166 字）→ 易混部首 30 关（295 字：曾有来源分歧或康熙部首与规范不同的字，如 去、有、对、灭）。每档按字频由易到难，每档第 1 关直接开放。
- 干扰项：该字的其他部件（IDS）、康熙部首/其他来源给出的部首、形近部首组（日/曰/目/月、礻/衤、冫/氵、阝 左右 等），四个选项主部首互不相同。
- 部首名称：按位置命名（左旁用 提土旁/禾木旁/三点水…，上为「X字头」，下为「X字底」，本字即部首注明），阝 区分左耳旁（阜）/右耳旁（邑）。`build/bushou/names.py`。
- 读音：复用已有 `audio/zi/`，缺的 2065 个字用同一 edge-tts 声音 zh-CN-XiaoxiaoNeural（-10%）补齐，多音字仍用同音单音字替读；新增语音 常见部首/少见部首/易混部首/答对了/再看看。
- 存档：`pinciwang.v1` 升到 v4；旧后花园的金币与礼包计时迁到新后花园，旧进度保存在 `G.bonusOld`；主园存档不动。
- 抽样：30 道随机题与各来源逐题对照，全部无误；Playwright 390px 与桌面端跑通迁移、答题、过关、易混档进关，控制台零错误。
- 重新生成：`cd build && python3 build_bushou.py && python3 tts_bushou.py && python3 subset_callig.py`（原始来源与扫描核对脚本在构建机 scratch，`sources_3500.json` 已保存核对结果）。

## v7（多设备适配，按 UI UX Pro Max 响应式规范）
